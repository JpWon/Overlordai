# Overlord AI — Site

Static site for **Overlord AI**, the desktop gaming co-pilot — a live guidebook
companion that reads your screen and talks you through the game.

## Pages

- `index.html` — home (hero, live callouts, preview, FAQ, footer)
- `plans.html` — pricing (free demo / subscription / pro; monthly & yearly)
- `login.html` — sign in / create account
- `support.html` — contact, FAQ, legal

## Stack

Plain HTML + CSS + vanilla JS. No build step. Fonts load from Google Fonts;
the light/dark theme persists to `localStorage`.

## Status

Some copy, imagery and legal content are still placeholders — see the
`REPLACE` image markers and the FAQ/legal sections on `support.html`.
