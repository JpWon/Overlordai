# Legal pages — how they are built

Three documents: **EULA**, **Privacy Policy**, **Terms of Service**. They share the site's chrome
(nav, drawer, footer, JS) and a single prose stylesheet, so the chrome lives in exactly one file.

```
legal/_skeleton.html        site chrome + the .lg-* stylesheet   <- edit the chrome HERE
legal/eula.content.html     the document itself (fragment)       <- edit the words HERE
legal/privacy.content.html
legal/terms.content.html
legal/build_legal.py        splice: skeleton + fragment -> page
legal/DECISIONS.md          the open questions, for the owner to answer later (not served, not in the sitemap)
    |
    +--> eula.html, privacy.html, terms.html   (generated, committed, served by Vercel)
```

Rebuild after any edit:

```bash
cd ~/Downloads/My\ Stuff/overlord-homepage-preview
python3 legal/build_legal.py            # all three
python3 legal/build_legal.py privacy    # one
```

Rules

- **Never edit a generated page.** `eula.html` / `privacy.html` / `terms.html` are overwritten on
  every build. Change the fragment, then rebuild.
- A fragment is an HTML5 **fragment**: no `<html>`, no `<head>`, no meta tags and no `<style>`.
  Metadata (title, description, canonical, Open Graph, JSON-LD, sitemap) is generated by
  `~/.hermes/cache/scratch/add_site_metadata.py`, which lists all three pages in `PAGES`.
- Use only the classes the skeleton already defines: `lg__label`, `lg__meta`, `lg__lede`,
  `lg__toc`, `lg__note`, `lg__end`, plus `section`/`h2`/`h3`/`p`/`ul`/`ol`/`li`/`table`. Styling a
  new element means editing the skeleton, which changes all three documents at once — that is the
  point, not a side effect.
- **A table must never widen the page.** Mark a table that can get wide `class="lg-stack"` and give
  every cell except the first a `data-label`; the skeleton stacks such a table into labelled blocks at
  ≤700 px and prints the label from `td[data-label]::before`. The five-column plans table in
  `terms.content.html` pushed the page to 475 px in a 390 px viewport without this; the three-column
  tables fit unmarked. Check every page at both widths — `node ~/.hermes/cache/scratch/overflow_audit.mjs
  http://127.0.0.1:3000 390,360` reports `page <sw>/<vw>` per page and names the offending element;
  the legal pages must read `390/390` and `360/360`.
- Square-bracket tokens in UPPERCASE are **undecided facts** (`[LEGAL ENTITY NAME]`,
  `[GOVERNING LAW]`, `[REFUND POLICY]`, …). Each fragment opens with a `DECISIONS BEFORE
  PUBLICATION` comment listing them. Do not fill one in without a decision from the owner, and
  never invent an entity, a jurisdiction, an address, a retention period or a certification.
- The documents must agree with each other and with the rest of the site — in particular the FAQ
  answers on `index.html` / `support.html` and the data-flow map on the product's own privacy page
  (`overlord-site/app/privacy/page.tsx`). Prices: Subscription $14.99/mo or $149.99/yr (one
  licence), Pro $39.99/mo or $399.99/yr (three licences), Demo $0 for 30 minutes of runtime.
